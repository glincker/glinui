  ## Usage

  `RevealText` is a `"use client"` component. It reveals text with a CSS `clip-path` wipe when scrolled into view via `IntersectionObserver`.

  ## Engines

  `Reveal Text` drives its main animation through the pluggable motion engine. Pass `engine="css" | "motion" | "gsap"`, wrap a subtree in `MotionEngineProvider`, or set `data-glin-engine` on `<html>`. The css engine is built in and dependency free; `motion` and `gsap` are opt-in through `@glinui/motion/register/*`. Motion level `none` renders the final state and `subtle` is opacity only.

  ## Accessibility

  - The text content is always present in the DOM for screen readers.
  - The animation is purely visual via `clip-path`.

  ## Reduced Motion

  When `prefers-reduced-motion: reduce` is active, the text is shown immediately with no animation.
