  ## Usage

  Pass a `text` string. As the user scrolls, each word fades from dim to full opacity, creating a reading-pace reveal effect.

  ## Engines

  `Text Reveal` drives its main animation through the pluggable motion engine. Pass `engine="css" | "motion" | "gsap"`, wrap a subtree in `MotionEngineProvider`, or set `data-glin-engine` on `<html>`. The css engine is built in and dependency free; `motion` and `gsap` are opt-in through `@glinui/motion/register/*`. Motion level `none` renders the final state and `subtle` is opacity only.

  ## Accessibility

  - All text is in the DOM and readable by screen readers at all times.
  - Opacity is visual only, content is never hidden from assistive technologies.

  ## Reduced Motion

  When `prefers-reduced-motion` is active, all words are immediately shown at full opacity.
