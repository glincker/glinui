  ## Usage

  `RippleButton` is a `"use client"` component. Press it to see a ripple expand from the pointer position. The ripple uses the surface text colour at 30 percent, so it reads on light and dark scopes. Override with `rippleColor`.

  ## Examples

  ### Variants

  Every variant of the shared vocabulary works, and the motion effect adapts to the surface colour. Omit `variant` for the ambient default (`glinr`).

  ### Glass (opt-in)

  `glass` is never the default. It needs a colorful or photographic backdrop to read, so place it over imagery or inside a `ThemeScope` with a backdrop.

  ## Accessibility

  - Renders through `Button`: native `<button>`, 2px accent focus ring with offset, `disabled` and `aria-busy` states.
  - Accessible name comes from the label. Decorative effect layers are `aria-hidden` and `pointer-events-none`.
  - Defaults to `type="button"`.

  ## Reduced Motion

  No ripple is created under `prefers-reduced-motion` or `data-glin-motion="none"`. The click handler still runs.
