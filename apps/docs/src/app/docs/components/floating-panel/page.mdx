  ## Usage

  `FloatingPanel` is a `"use client"` component. Place it inside a relative container. Drag to reposition.

  Drag either panel inside its container. The default surface is the glinr lift look with elevation 3, so it reads on any backdrop.

  ## Examples

  ### Variants

  `glinr` is the default, `plain` is the flat shadcn look, `solid` is a neutral tonal face and `glass` is opt-in. Glass needs a backdrop, so the set below sits on a vivid one.

  ## Accessibility

  - Close button has `aria-label="Close panel"`.
  - Drag interaction uses Pointer Events API for broad device support.
  - Interactive elements inside the panel (buttons, links) are not affected by drag.

  ## Reduced Motion

  No animation is used, drag is position-based, not animated.
