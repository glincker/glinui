  ## Usage

  Renders a number that counts up from `from` to `value` when scrolled into view. Uses `requestAnimationFrame` for smooth 60fps animation.

  ## Engines

  `Number Ticker` drives its main animation through the pluggable motion engine. Pass `engine="css" | "motion" | "gsap"`, wrap a subtree in `MotionEngineProvider`, or set `data-glin-engine` on `<html>`. The css engine is built in and dependency free; `motion` and `gsap` are opt-in through `@glinui/motion/register/*`. Motion level `none` renders the final state and `subtle` is opacity only.

  ## Accessibility

  - Renders as a `<span>` with `tabular-nums` for stable width during counting.
  - Add `aria-label` to the parent if the number has semantic meaning beyond decoration.

  ## Reduced Motion

  When `prefers-reduced-motion` is active, the final value is displayed immediately without animation.
