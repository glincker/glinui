  ## Usage

  `LiquidButton` extends `Button`. The default is a crisp `glinr` surface; on hover or focus an accent liquid fill rises through it. The fill is an accent mix (override with the `--liquid-fill` custom property), so it reads on light and dark scopes. It accepts every `Button` prop and adds `intensity`.

  ## Examples

  ## Accessibility

  - Renders through `Button`: native `<button>`, 2px accent focus ring with offset, `disabled` and `aria-busy` states.
  - Accessible name comes from the label. Decorative effect layers are `aria-hidden` and `pointer-events-none`.

  ## Reduced Motion

  Scale, brightness and the fill transition are disabled under `prefers-reduced-motion` and `data-glin-motion="none"`.
