  ## Usage

  Wrap any container with `position: relative` and place `BorderBeam` inside. The beam travels along the border using CSS `offset-path`.

  A beam of accent light travels the edge of a glinr metrics card. The beam is a decorative overlay, so the card underneath keeps its normal surface.

  ## Examples

  ### Variants

  `glinr` is the default, `plain` is the flat shadcn look, `solid` is a neutral tonal face and `glass` is opt-in. Glass needs a backdrop, so the set below sits on a vivid one.

  ## Engines

  The `engine` prop is not applicable. Looping offset-path beam in css; path driven. It stays css only and still honors motion level `none` and reduced motion.

  ## Accessibility

  - `BorderBeam` is purely decorative and does not receive focus.
  - No interactive elements, safe for screen readers.

  ## Reduced Motion

  The beam animation uses `motion-reduce:hidden`. Under `prefers-reduced-motion`, the beam is hidden entirely.
