  ## Usage

  `MagneticCTA` wraps a `Button` and pulls it toward the cursor inside the magnetic radius. The default is a crisp `glinr` surface that adapts to the theme scope, so it looks right on every stage backdrop. The button stays fully accessible; the pull is a decorative transform.

  ## Examples

  ### Glass (opt-in)

  `glass` is never the default. It needs a colorful or photographic backdrop to read, so place it over imagery or inside a `ThemeScope` with a backdrop.

  ### Custom offset and radius

  Increase `maxOffset` for a stronger pull and `magnetRadius` to activate the effect from further away.

  ## Accessibility

  - Renders through `Button`: native `<button>`, 2px accent focus ring with offset, `disabled` and `aria-busy` states.
  - Accessible name comes from the label. Decorative effect layers are `aria-hidden` and `pointer-events-none`.
  - The focus ring stays on the button and is not hidden by the offset.

  ## Reduced Motion

  The pull is disabled under `prefers-reduced-motion` and `data-glin-motion="none"`: the offset resets to zero.
