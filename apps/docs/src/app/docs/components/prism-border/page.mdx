  ## Usage

  Wrap any content with `PrismBorder` to add an animated rainbow refraction border. Uses CSS mask compositing for the hollow border effect.

  A moving spectrum border frames a profile card. The border is the star, the card inside is a regular glinr card.

  ## Examples

  ### Variants

  `glinr` is the default, `plain` is the flat shadcn look, `solid` is a neutral tonal face and `glass` is opt-in. Glass needs a backdrop, so the set below sits on a vivid one.

  <ExampleBlock
    code={`import { PrismBorder, Card } from "@glinui/ui"

// Omit variant to follow the ambient style (glinr by default).
export function PrismBorderVariants() {
  return (
    <>
      <PrismBorder borderWidth={2}>
  <Card variant="glinr" className="rounded-[inherit]">
        ...
        </Card>
</PrismBorder>
      <PrismBorder borderWidth={2}>
  <Card variant="plain" className="rounded-[inherit]">
        ...
        </Card>
</PrismBorder>
      <PrismBorder borderWidth={2}>
  <Card variant="solid" className="rounded-[inherit]">
        ...
        </Card>
</PrismBorder>
      <PrismBorder borderWidth={2}>
  <Card variant="glass" className="rounded-[inherit]">
        ...
        </Card>
</PrismBorder>
    </>
  )
}`}
  >

  ## Accessibility

  - The animated border element is `aria-hidden="true"`, invisible to assistive technologies.
  - Content inside the border wrapper remains fully accessible.

  ## Reduced Motion

  The gradient animation is paused via `motion-reduce:[animation:none]`. A static gradient border remains visible.
